---
description: Convene a PMCR-O round table on a topic, e.g. /pmcro-seats:round-table executive what should we sell first?
argument-hint: [executive | seat,seat,...] <topic>
---

Use the round-table skill with "$ARGUMENTS". If the first word is a table name or a comma-separated list of seat ids, that is the table; otherwise use the executive table and treat everything as the topic.
