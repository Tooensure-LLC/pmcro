# pmcro-seats

Talk to the PMCR-O C-Suite. Each of the company's 15 seats is a separate, read-only agent that answers only inside its own boundary. You can ask one seat, or convene a round table where the Chief of Staff chairs and the seats speak in a fixed order.

## Skills

| Skill | Use it to |
| --- | --- |
| `round-table` | Convene several seats on one topic, chaired by the Chief of Staff; founder-first items are listed, never decided. Also prints one seat's card for asking it alone. |

## Commands

| Command | Does |
| --- | --- |
| `/pmcro-seats:ask [seat] <message>` | Asks one seat, e.g. `/pmcro-seats:ask cfo can we afford a cloud model this week?`. Without a seat id, the Chief of Staff routes the message to the one owning seat. |
| `/pmcro-seats:round-table [table or seats] <topic>` | Runs the round-table skill, e.g. `/pmcro-seats:round-table cfo,cto,cmo what should we sell first?` |

## Agents

One per seat, in `agents/`, all with read-only tools (Read, Grep, Glob): chief-of-staff, ceo, cto, cto-checker, cpo, cdo, ciso, coo, cfo, clo, chief-agent-officer, cro, cmo, cco, auditor. They are generated by `tools/seats.py gen` from `skills/round-table/assets/seats.json`, a snapshot of the company repo's `company.json` (commit recorded in the file). Never edit them by hand; CI runs `tools/seats.py gen --check`.
