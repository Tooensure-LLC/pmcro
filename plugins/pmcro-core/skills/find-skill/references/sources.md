# Where else to look

1. This repository: `scripts/find_skill.py` (plain-text search over every plugin's skills).
2. dotnet/skills, pinned in `upstream.json`: .NET, MAUI, MSBuild, testing, upgrade and more. MIT licensed; reference it, do not copy it.
3. The Agent Skills documentation server, when connected as an MCP server: the specification, best practices (including gotchas and description-writing) and how to evaluate a skill. It serves documentation pages, not a registry of skills.
4. This repository's own MCP skills server (`mcp-server-factory`), when a client is connected to it: it lists every skill with its description.
5. The owner's other repositories and the Cloudflare, GitHub and Figma skill sets, by name.

Record what you checked, with the date: these sources change.
