An MCP server wrapping a platform API is a tool: fixed, decides nothing. A workflow is deterministic code and is what guarantees a Trail frame is written and gates run. An agent is a model that chooses among the tools its role allows. Owner wording on macro and micro workflows differs from the Runtime corpus wording; which is canonical is undecided (docs/product/company-model.md). ADR 0026.
