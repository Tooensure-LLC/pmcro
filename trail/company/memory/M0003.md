Per Upwork's own help pages (search snippets, not the full terms): its API does not allow submitting proposals or bidding, bots acting faster than a human are restricted, and it publishes an MCP for AI agents and an AI Agent Playground for approved AI partners. Pattern: record each platform's permitted path and limits before first use (EC-0002), use the official agent route, flag red-flag sites for the owner, get approval before the first public action, and move to the next channel when a limit is hit. Agents act under their own disclosed identity; the owner is still the registered owner of accounts. Backlog rows 40, 42, 43, 44.
