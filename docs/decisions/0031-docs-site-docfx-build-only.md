# 0031: Docs site with docfx 2.81.0: curated public pages, built and checked, never deployed by agents

Date: 2026-10-02. Status: built; see Consequences for what was and was not tested. Asked for by the founder ("get the site visual", full approval for this change in chat).

## Context

The repo has rich Markdown under `docs/` but no rendered site. The founder asked for a production-grade .NET docs site using the current docfx. On 2026-10-02 NuGet listed docfx **2.81.0** (published 2026-09-25, targets net8.0, runs on .NET 8, 9, 10 and 11) as the latest stable version; its "modern" template is the current built-in one and is customised by stacking a template folder with `public/main.css` and `public/main.js`. ADR 0011 says site work builds and checks while humans deploy, and the company's open queue item on confidentiality says not to publish all of `docs/` until it is resolved.

## Decision

- `site/` holds the site: `docfx.json`, `toc.yml`, a landing page (`index.md`), a docs index (`docs.md`), the generated plugin catalog (`plugins.md`), brand art in `images/` and the `templates/pmcro` layer over `default` + `modern`.
- docfx is pinned as a local dotnet tool, `.config/dotnet-tools.json` (2.81.0, no roll-forward). Upgrades are a deliberate one-line change.
- **Curated, not wholesale.** `site/docfx.json` names each page it copies from `docs/`: the marketplace, dotagents, offline-kit and imports guides, `product/trail.md`, `product/foundations.md` and all decision records. Company-model, backlog, training-data, competitor and review pages are not built. Adding a page is an explicit edit to that list.
- `site/plugins.md` is generated by `tools/site_catalog.py` from `.claude-plugin/marketplace.json`; CI runs `gen --check` so the page cannot drift.
- CI job `docs-site` restores the pinned tool and builds the site with warnings treated as errors. It uploads nothing and deploys nothing. The output folder `site/_site/` is git-ignored.
- Visual identity: "Fund The Loop", navy `#0B1026`, orange `#FF8A3D`, magenta `#E0389A`, gold `#FFC24B`. The SVG logo, favicon and hero (the five roles on an infinity loop) are original art generated for this repo; no third-party marks.
- No sitemap and no canonical URL yet: there is no chosen host, and inventing one would be false metadata.

## Consequences

- Deploying (GitHub Pages, Cloudflare or anything else), choosing a domain and adding a sitemap stay with the founder (ADR 0011), and should wait for the confidentiality queue item.
- Tested: see the pull request for the real `docfx build` output on Windows with the pinned tool, and the CI run.
- Not tested: PDF output (disabled), search quality, screen readers, browsers other than the one used for screenshots, and Windows PowerShell 5.1.
